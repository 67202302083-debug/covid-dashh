แนะนำการนำแดชบอร์ดนี้ไปติดตั้งใช้งานจริงบน GitHub Pages:

  1. สร้าง Repository ใหม่บน GitHub.com (ตั้งชื่อ เช่น covid19-dashboard)
  2. อัปโหลดไฟล์ HTML นี้โดยบันทึกชื่อเป็น index.html ขึ้นไปที่ Root directory ของ Repository
  3. ไปที่เมนู Settings > Pages ของ Repository
  4. ภายใต้หัวข้อ Source ให้เลือก Branch เป็น main (หรือ master) แล้วกด Save
  5. ระบบจะสร้างลิงก์เว็บไซต์ออนไลน์ทันที เช่น https://username.github.io/covid19-dashboard/ สามารถเปิดดูได้ทุกอุปกรณ์และแชร์ให้ทีมงานได้เลย!
